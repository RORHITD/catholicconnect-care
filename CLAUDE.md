# catholicconnect-care

Next.js 16 (App Router) + TypeScript + Tailwind v4 rebuild of the WordPress site at https://catholicconnect.care.

## Stack
- **Framework:** Next.js 16 (App Router, Turbopack)
- **Runtime:** Bun
- **Language:** TypeScript (strict)
- **Styling:** Tailwind v4 (`@theme` in `app/globals.css`)
- **Fonts:** Playfair Display (display) + Inter (body)
- **Donations:** Donorbox embed — campaign `the-catholic-connect-foundation`
- **Email:** Resend (set `RESEND_API_KEY`, `RESEND_FROM_EMAIL`, `CONTACT_RECIPIENT_EMAIL`)

## Layout
- `app/` — App Router routes (one folder per page slug to match WP URLs)
- `app/[slug]/page.tsx` — dynamic blog post route at root level (matches WP URL structure)
- `app/category/[slug]/page.tsx` — blog category archive
- `components/site/` — header, footer
- `components/sections/` — reusable page sections (hero, feature-grid, testimonials, why-choose, commit-to-giving)
- `components/donorbox/` — Donorbox iframe component
- `components/forms/` — client-side forms
- `lib/` — utilities (`wp-utils.ts`, `rss.ts`)
- `data/` — WP REST API exports (pages, posts, categories, image-map) — generated by `scripts/extract-wp.ts`
- `public/wp/` — locally mirrored WP media (images + hero video)
- `scripts/extract-wp.ts` — re-runnable WP content extractor

## Re-fetching content from WordPress
```bash
bun run scripts/extract-wp.ts
```
This refreshes `data/*.json` and downloads any new images to `public/wp/`.

## Design tokens
Colors: `burgundy-{50..900}`, `gold-{50..900}`, `cream-{50..200}`, `stone-warm-{50..900}`, `ink`. Defined in `app/globals.css` via `@theme`.

## Donations
The Donorbox embed component (`components/donorbox/donorbox-embed.tsx`) defaults to the foundation's campaign. All donate-style pages use it with `defaultInterval="m"` (monthly).
